# HR Attrition Analysis Dashboard | Power BI

## Project Overview
The HR Attrition Analysis Dashboard is an interactive Power BI project designed to analyze employee attrition and identify workforce trends. It helps HR teams understand employee turnover across different departments, age groups, genders, job roles, and job satisfaction levels.

## Objectives
- Analyze total employees and employee attrition.
- Calculate the employee attrition rate.
- Identify departments with higher employee attrition.
- Analyze attrition by gender and age group.
- Understand attrition across job roles and job satisfaction levels.
- Present HR insights through an interactive dashboard.

## Tools & Technologies
- Microsoft Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- Data Visualization
- Data Cleaning and Analysis

## Key Performance Indicators (KPIs)
- **Total Employees:** 1,470
- **Attrition Count:** 201
- **Attrition Rate:** 13.67%
- **Average Monthly Income:** Approximately 6.5K

## Dashboard Features
- Employee attrition by department
- Employee attrition by gender
- Attrition by age group
- Employee attrition by job role
- Attrition by overtime
- Attrition by job satisfaction

## Key Insights
- The overall employee attrition rate is approximately 13.67%.
- Research & Development has the highest attrition count among the departments in this dataset.
- Attrition patterns can be explored across age groups, gender, job roles, and overtime.
- The dashboard helps HR teams explore workforce trends and support data-driven decisions.

## Skills Demonstrated
- Data preparation and cleaning
- DAX measures and calculations
- KPI development
- Interactive dashboard design
- Data visualization and interpretation

## Conclusion
This project demonstrates how Power BI can be used to analyze HR data, monitor employee attrition, and communicate workforce insights through an interactive dashboard.
